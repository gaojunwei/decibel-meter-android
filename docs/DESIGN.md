# 功能设计

## 定位

单一用途、离线运行，无注册、账户、广告、后台录音和历史录音管理。

## 界面与流程

主页面展示实时仪表盘、状态、最小/最大/Leq、近 60 秒趋势、时长、暂停与重置。设置页提供环境类别、提醒阈值、校准偏差、常亮和主题；设置保存在本地 WebView 存储。应用首次启动申请麦克风权限，用户拒绝时提供提示。退出前台停止采集，返回前台按之前的运行状态继续。

## 数据流

AudioRecord（48 kHz、PCM16、单声道）→ 原始音源优先，否则 VOICE_RECOGNITION → 工作线程读取 → Base64 编码 PCM → 受限 WebView 桥接 → JS A 计权近似滤波、RMS 能量计算 → 实时界面。每 9600 样本生成一次约 200 ms 声级。UI 忙时丢弃未及时处理的数据，统计时长是已处理样本时长而非绝对墙钟时间。音频仅用于实时处理，不写入文件。

滤波采用六级一阶高/低通组合并在 1 kHz 归一化。估算声级 L = 10 log10(均方能量) + 100 + 校准偏差；Leq 按有效样本能量累计，不能直接算 dB 的算术平均。校准偏差范围 ±30 dB，调整后重置本次统计。过载检测依据 PCM 峰值。滤波近似、硬件频响和增益均可能影响准确性。

## 阈值

应用自定义分级：<35 非常安静；35–<50 安静；50–<65 正常；65–<80 吵闹；80–<95 非常吵闹；≥95 极度吵闹。持续超自定义阈值约 3 秒显示提示（默认 80 dB），不播放警报音，避免影响测量。

## 安全设计

仅声明 RECORD_AUDIO；不申请 INTERNET；本地页面禁止外部导航及网络加载，不允许普通文件及内容访问；只有本地受信任页面使用桥接。无遥测 SDK。无后台服务。应用设置本地保存，关闭自动备份。
