# 使用及验收清单

首次打开允许麦克风权限。仪表盘显示估算 dB(A) 与环境等级。暂停后保持已显示数据；重新检测清零统计。设置页可选择环境参考、阈值、主题、常亮及校准。

校准：与可信的声级计放在同一稳定声场，保持相近位置和方向，比较一段时间的 Leq，输入两者之差。建议在不同声级复核。单点偏差无法补偿频响或增益变化。
